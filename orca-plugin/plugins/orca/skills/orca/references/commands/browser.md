# Built-in browser automation

> Generated by `scripts/build_reference.py` from `orca agent-context --json` (schema v1, Orca 1.4.214, source commit bf71d64). Regenerate after upgrading Orca; the live CLI (`orca <command> --help`) wins on any disagreement.

Orca's embedded, worktree-scoped browser tab. Snapshot -> act -> re-snapshot.

**Top-level commands:** `back`, `browser`, `capture`, `check`, `clear`, `click`, `clipboard`, `console`, `cookie`, `dblclick`, `dialog`, `download`, `drag`, `eval`, `exec`, `fill`, `find`, `focus`, `forward`, `full-screenshot`, `geolocation`, `get`, `goto`, `highlight`, `hover`, `inserttext`, `intercept`, `is`, `keypress`, `mouse`, `network`, `pdf`, `reload`, `screenshot`, `scroll`, `scrollintoview`, `select`, `select-all`, `set`, `snapshot`, `storage`, `tab`, `type`, `uncheck`, `upload`, `viewport`, `wait`
