# Mobile emulators and desktop computer use

> Generated by `scripts/build_reference.py` from `orca agent-context --json` (schema v1, Orca 1.4.214, source commit bf71d64). Regenerate after upgrading Orca; the live CLI (`orca <command> --help`) wins on any disagreement.

iOS Simulator / Android emulator control and native desktop app automation.

**Top-level commands:** `computer`, `emulator`

## Commands

### `orca computer capabilities`

Show computer-use provider capabilities

```text
orca computer capabilities [--json]
```

**Flags:** `--json`, `--pairing-code`, `--environment`

### `orca computer click`

Click an app element or window coordinate, optionally with modifiers

```text
orca computer click --app <app> (--element-index <n> | --x <x> --y <y>) [--window-id <id> | --window-index <n>] [--click-count <n>] [--mouse-button <left|right|middle>] [--modifiers <modifier-chord>] [--restore-window] [--no-screenshot] [--json]
```

**Flags:** `--json`, `--pairing-code`, `--environment`, `--worktree`, `--session`, `--app`, `--window-id`, `--window-index`, `--restore-window`, `--no-screenshot`, `--element-index`, `--x`, `--y`, `--click-count`, `--mouse-button`, `--modifiers`

### `orca computer drag`

Drag between app elements or window coordinates

```text
orca computer drag --app <app> (--from-element-index <n> --to-element-index <n> | --from-x <x> --from-y <y> --to-x <x> --to-y <y>) [--window-id <id> | --window-index <n>] [--restore-window] [--no-screenshot] [--json]
```

**Flags:** `--json`, `--pairing-code`, `--environment`, `--worktree`, `--session`, `--app`, `--window-id`, `--window-index`, `--restore-window`, `--no-screenshot`, `--from-element-index`, `--to-element-index`, `--from-x`, `--from-y`, `--to-x`, `--to-y`

**Flags:** `--json`, `--pairing-code`, `--environment`, `--worktree`, `--session`, `--app`, `--window-id`, `--window-index`, `--restore-window`, `--no-screenshot`
